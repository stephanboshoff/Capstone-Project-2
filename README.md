# Capstone-Project-2

A responsive and modern personal portfolio website showcasing my work, skills, and background as a junior web developer. 
Built with HTML, Bootstrap 5, and custom CSS, this project serves as my public-facing developer profile and a foundation I can expand as I grow in the field.

Features

-Fully responsive layout using Bootstrap’s grid system
-Clean hero section introducing who I am
-Skills section highlighting professional and technical abilities
-Project showcase with live link and preview image
-Organized footer with navigation links
-Custom styling through styles.css

Tech Stack

-HTML5
-Bootstrap 5.3.8
-CSS3
-Local image assets
